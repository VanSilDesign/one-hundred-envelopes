✉️ One Hundred Envelopes
A Gamified Saving Application

One Hundred Envelopes is a web application designed to help users save money through the "100 Envelopes Challenge." The app transforms a traditional saving method into a digital, interactive experience. By clicking a button, the system generates a random amount; the user then "transfers" that sum from their virtual wallet to a digital piggy bank, tracking their progress toward the final goal.
🛠 Tech Stack

  - Frontend: React.js (Hooks, Functional Components)

  - Backend: Node.js & Express

  - Database: MongoDB (Handling user progress and transaction history)

  - Authentication: Passport.js (Secure user login and session management)

  - Styling: CSS3 / Responsive Design

✨ Key Features

  - Interactive Gamification: A seamless UI that handles the random generation of "envelope" amounts.

  - Full-Stack Integration: Currently implementing MongoDB to persist user data, ensuring that the saving progress is saved across different sessions.

  - Secure Authentication: Integrating Passport.js to provide a personalized and secure experience for every user.

  - Responsive UI: Optimized for both desktop and mobile use, focusing on high-quality UX/UI principles.
